🔐 Swagger Auth Testing Guide

How to test authenticated endpoints in Swagger UI.

Quick Start

Open http://localhost:4000/api/docs in your browser.

Step-by-Step

1Login to get a token

Find POST /api/auth/login and send:

{
  "email": "admin@booknest.ir",
  "password": "admin123"
}

Copy the accessToken from the response.

2Authorize in Swagger

  1. Click the "Authorize" button (top right of Swagger)
  2. In the "Bearer" field, paste your token (without "Bearer " prefix)
  3. Click "Authorize"
  4. Close the dialog — you're now authenticated!

3Test protected endpoints

Now try any endpoint with 🔒 — it will use your token automatically.

Testing Flow

# 1. Register (no auth needed)
POST /api/auth/register
{ "email": "new@booknest.ir", "password": "pass12345", "firstName": "تست", "lastName": "کاربر" }

# 2. Login
POST /api/auth/login
{ "email": "new@booknest.ir", "password": "pass12345" }
# → Copy accessToken

# 3. Use token in Authorize dialog

# 4. Test endpoints
GET /api/books                    # Public - no auth needed
GET /api/auth/profile             # Protected - needs token
POST /api/cart/items              # Protected - needs token
GET /api/seller/dashboard         # Protected - needs SELLER role
GET /api/admin/dashboard          # Protected - needs ADMIN role
