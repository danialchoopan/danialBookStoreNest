🚀 Setup Guide

Get BookNest running in under 5 minutes. No Docker required — uses SQLite.

Prerequisites

RequirementVersionCheck Command
Node.js18+node --version
npm9+npm --version
Windows users: If npm install hangs, your ISP may be blocking npm. Try: npm config set registry https://registry.npmjs.org/ or use a VPN.

Quick Setup (3 Commands)

# 1. Clone
git clone https://github.com/danialchoopan/danialBookStoreNest.git
cd booknestjsshop

# 2. Setup & run backend
cd backend && npm install && npx prisma generate && npx prisma migrate dev --name init && npm run prisma:seed && npm run start:dev

# 3. Setup & run frontend (new terminal)
cd frontend && npm install && npm run dev

Step-by-Step Setup

1Clone the repository

git clone https://github.com/danialchoopan/danialBookStoreNest.git
cd booknestjsshop

2Install backend dependencies

cd backend
npm install

3Setup database (SQLite — no Docker needed)

npx prisma generate       # Generate Prisma client
npx prisma migrate dev --name init  # Create database
npm run prisma:seed       # Seed with sample data
This creates backend/prisma/dev.db with 30 books, 25 reviews, 22 orders, and sample users.

4Start the backend

npm run start:dev

Backend running at: http://localhost:4000

Swagger docs at: http://localhost:4000/api/docs

5Open a new terminal and setup frontend

cd ../frontend
npm install

6Start the frontend

npm run dev

Frontend running at: http://localhost:3000

7Login and test!

Go to http://localhost:3000/login and use the demo accounts below.

Optional: Docker Setup

If you prefer PostgreSQL + Redis instead of SQLite:

# Start PostgreSQL + Redis
docker-compose up -d

# Update backend/.env
DATABASE_URL="postgresql://booknest:booknest_secret@localhost:5432/booknest_db"
REDIS_URL="redis://localhost:6379"

# Re-run migrations with PostgreSQL
npx prisma migrate dev --name init

Troubleshooting

ProblemSolution
npm install hangsSwitch registry: npm config set registry https://registry.npmjs.org/
prisma generate failsDelete node_modules and package-lock.json, then npm install
Port 4000 in useChange PORT in backend/.env
Port 3000 in useNext.js will auto-use 3001
Frontend can't connect to APICheck frontend/.env.local has NEXT_PUBLIC_API_URL=http://localhost:4000/api
Database errorsDelete backend/prisma/dev.db and re-run npx prisma migrate dev && npm run prisma:seed
